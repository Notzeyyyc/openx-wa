## Part 2: CLI Setup Tool

### New Package: `setup/`

```
setup/
├── index.js          — CLI entry point
├── commands/
│   ├── init.js       — Interactive setup wizard
│   ├── deploy-termux.js — Deploy MCP to Termux
│   ├── deploy-vps.js — Deploy bot to VPS
│   ├── tunnel.js     — Setup cloudflared/tailscale
│   └── status.js     — Check connection status
├── templates/
│   ├── .env.example  — Env template
│   ├── config.yaml   — MCP config template
│   ├── termux-setup.sh — Termux bootstrap script
│   └── vps-setup.sh  — VPS bootstrap script
└── package.json
```

### Commands

#### `setup init` — Interactive wizard
```
? Deployment mode: (VPS only / VPS + Android / Local only)
? AI Provider: (OpenRouter / REST / OpenAI-compatible)
? ADB Mode: (USB / TCP auto / Not needed)
? Tunnel type: (Cloudflared / Tailscale / None)
? Generate MCP auth token? (Yes / No)
→ Creates .env, config files, prints next steps
```

#### `setup deploy-termux` — Deploy MCP to Android
```
1. Checks Termux is available (via SSH or ADB)
2. Copies openx-mcp/ to Termux
3. Builds Go binary
4. Installs cloudflared (if tunnel mode)
5. Starts MCP server + tunnel
6. Prints public URL for VPS
```

#### `setup deploy-vps` — Deploy bot to VPS
```
1. Checks Node.js + pnpm available
2. Copies project files (excluding .env, caches)
3. Runs pnpm install
4. Configures .env with MCP URL + auth token
5. Starts bot (or installs as systemd service)
```

#### `setup tunnel` — Setup tunnel
```
? Tunnel type: (Cloudflared / Tailscale)

Cloudflared:
1. Installs cloudflared on Termux
2. Runs: cloudflared tunnel --url http://localhost:8765
3. Prints public URL
4. Updates VPS .env with URL

Tailscale:
1. Checks Tailscale installed on both devices
2. Shows Tailscale IP of Android device
3. Updates VPS .env with IP
```

#### `setup status` — Check everything
```
✓ WhatsApp bot: running (PID 12345)
✓ MCP server: reachable (http://localhost:8765)
✓ ADB: connected (USB device ABC123)
✓ Tunnel: active (https://xxxx.trycloudflare.com)
✓ AI provider: OpenAI (mimo-v2.5-pro)
```

### Tech Stack
- CLI framework: `commander` or `cac` (lightweight)
- Prompts: `inquirer` or `prompts`
- SSH: `ssh2` package (for remote Termux deployment)
- No heavy dependencies — keep it lean
