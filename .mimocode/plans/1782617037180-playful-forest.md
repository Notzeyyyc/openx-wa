# OpenXX Refactor: Productivity Assistant

## Goal
Pivot dari Android automation ke pure AI productivity assistant. Hapus ADB + MCP, fokus ke belajar, kerja, dan produktivitas.

## Scope

### Remove
- `src/adb-connect.js` — ADB port detection
- `src/adb-helper.js` — ADB commands
- `openx-mcp/` — MCP server (Go)
- ADB-related code in `src/whatsapp/` (commands, ai-processor tags)
- MCP client code (`src/whatsapp/mcp-client.js`)
- ADB config in `.env`
- MCP config in `.env`

### Keep
- WhatsApp bot core
- AI providers (OpenAI, Claude, ChatGPT, Gemini, OpenRouter)
- Agent system (homework, essay, solver, research, translate, vision)
- Group management (welcome, spam, auto-reply)
- Analytics
- Music player
- Conversation memory
- Plugin system
- CLI setup tool

### New Features
- **Notes** — simpan catatan via WhatsApp
- **Reminders** — set pengingat via WhatsApp
- **Web Search** — cari informasi via AI
- **Translate** — translate text
- **Summary** — rangkum text panjang
